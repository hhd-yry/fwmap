# 鉴权证据词表：handler 或其调用者中出现即视为"有鉴权"。
# 两类条目：
#   func <名字>     已知鉴权函数，匹配 <名字>( 调用（词边界，避免子串误配）
#   inline <正则>   内联会话检查模式（不区分大小写），如 cookie/session 标识解析
#
# 只回答"有没有鉴权证据"，不证明"鉴权实现是对的"。
# 实现可绕过（弱比较、可预测 token）仍属人工复核范围。
