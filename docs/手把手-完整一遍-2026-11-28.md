## 第三段　触发矩阵（最重要）

```powershell
py -3 lab\walk6_matrix.py
py -3 lab\walk7_matrix2.py
```

**实测结论**：

| 请求 | 结果 |
|---|---|
| `GET /login.cgi`（无查询串） | **崩** |
| `GET /login.cgi?`（光问号） | 正常 |
| `GET /login.cgi?graph_id=`（空值） | 正常 |
| `GET /login.cgi?graph_id`（无等号） | 正常 |
| `GET /login.cgi?x=1`（不相干） | 正常 |
| `POST /login.cgi`（任意 body，含正确参数） | **全部崩** |
| 对照：`GET /apply.cgi`、`/ping_response.cgi` | 正常 |

**结论**：不是"缺 `graph_id`"，而是 **GET 不带查询串** / **任何 POST**。
漏洞本身不变（单请求、无认证、可复现），**变的是归因**。

> 汇报时就讲这一步：我们假设是缺参数，设计了矩阵去验证，结果**自己把假设推翻了**。
