### 2. 修 A：完成状态与退出码

- `loop.run()` 新增 `status` / `stop_reason` / `pending` / `handoff`；
- 状态五取一：`completed` / `budget_exhausted` / `no_progress` /
  `dependency_missing` / `failed`；
- 退出码：0 完成 / 2 未完成 / 3 依赖缺失 / 4 写不出去；
- **无进展检测**：连续 3 步候选、证据、结论都没变化就停。

### 3. 修 B：证据强度与归因

- `verdict` 校验加三条：必须有引用、必须提到对象本身、长度必须对得上；
- 结论带 `support`：`observed-only`（只有空响应）vs `process-exit`（有独立退出记录）；
- 删掉"模型没给引用时由程序补一行"的逻辑 —— 那是伪造证据；
- 归因拆成 `model_steps` / `rule_steps` / `fallback_steps`，
  关模型时兜底数为 0；`verdict_accept_rate` 无尝试时返回 `null`（"不适用"）。
